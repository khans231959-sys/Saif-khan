HTML Meta Tags Audit

Assignment 19: Check important meta tags and make sure earlier HTML files contain the required metadata.

Meta Tags Checklist

Meta Tag Purpose Status
charset Supports correct text encoding. Included
viewport Helps pages fit mobile screens. Included
description Describes the page content. Included
author Identifies the page author. Included
title Sets the browser tab title. Included

How to Audit Earlier HTML Files

  1. Open each earlier HTML file in VS Code.
  2. Find the <head> section.
  3. Check whether the charset and viewport tags exist.
  4. Add any missing description or author metadata if appropriate.
  5. Save the file and test it in a browser.
Important: This page demonstrates the audit checklist. You must check and update your earlier HTML files separately. Creating this page alone does not audit or modify those files.
